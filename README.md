**SMS Spam Classifier**
A Machine Learning web application that classifies SMS messages as 
Spam or Not Spam (Ham) using Voting Ensemble Classifier.


**Technologies Used**

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- NLTK
- Jupyter Notebook
- Git & GitHub
- Steamlit
